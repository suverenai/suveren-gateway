# Agent process

Help the person set up the working AI's process in its own client. The process is the working AI's work, not the gateway's: the gateway only grants and checks what it may do.

## Write the process as steps

From the interview, for example:

1. Read new messages in the inbox.
2. Look up the customer in the CRM.
3. Check stock and price in the ERP.
4. Prepare the quote.
5. Reply to the customer.

Keep a fixed order of systems from the interview exactly as given; it is also a rule in the brief. The person confirms the steps.

## Where it lives

- In the working AI's client, as its standing instructions for this work, connected to this gateway.
- In a separate conversation or project from this setup conversation.

## What starts a run

- The person asks (for example: "Work the new requests.").
- Or a scheduled or triggered run, if the client offers one. Check what the person's client offers today; do not assume.

## When a step is unclear

The working AI stops and asks the person. It never fills a gap by guessing.

## Claude Desktop

Help the person connect the client to this gateway (the gateway's MCP address) and put the steps into the client's standing instructions for this work. Check the client's current settings with the person; menus change between versions.

## ChatGPT

Same as above: connect the gateway if the person's plan and client support custom MCP connectors, and add the steps as instructions. If connecting is not possible, say so — the working AI cannot be tested without the gateway.
